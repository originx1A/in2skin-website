How gift certificates and vouchers work, for the phone agent.

What a gift certificate is

A gift certificate is a code, looking like IN2-XXXX, emailed to the recipient. They choose their own time and redeem the code when they book.

What a caller can give

A Classic Facial ($85), an Anti-Aging Facial ($125), The Works ($160), or any amount they choose. Custom amounts start at $10.

How to buy one

On the website at boltonfacials.com/gift — it takes a minute, and the code is emailed straight to the recipient. The agent cannot take gift payment by voice. If the caller cannot use the website, take a message for the studio: their name, number, and what they want to give.

Redeeming a code

The recipient applies the code when they book, and the code’s value comes off their visit.

Voucher rules

Any leftover stays on the code for the person who used it. A voucher dies when the treatment is marked completed and its balance is $0. The dollar value never expires. No cash value. A no-show leaves the voucher valid.

Checking a balance

Voucher balances are checked by the studio. If a caller asks what is left on a code, take their name and the code, and take a message for the studio.
