# In2Skin — boltonfacials.com

Private one-on-one aesthetics studio in Bolton, Ontario. Public brand is
**In2Skin** only (legal entity: Funderwood). Live site: https://boltonfacials.com
(hosted on Vercel, free Hobby account).

> **Nothing here is deployed yet.** This repo is the complete Vercel-ready
> project. Deploy steps are in [DEPLOY.md](DEPLOY.md).

## What is in this repo

- `index.html` — the homepage (single-page app: services, booking wizard,
  gift certificates, pay on the spot, rule-based assistant chat).
  Design, copy and prices are the approved preview, wired to the real APIs.
- `assets/` — images, the 8 final videos, `qrcode.min.js` (vendored
  qrcode-generator 1.4.4), `site.css` (the homepage design system),
  `content.json` (services, prices, hours, payment answers — read by the chat).
- `classic-facial/`, `anti-aging-facial/`, `chemical-peels/`,
  `microneedling/`, `nano-needling/`,
  `microdermabrasion/`, `light-therapy/`, `reflexology/` — one static page
  per service for SEO (own video/photo, exact price, positive FAQ, booking
  CTA, Service + FAQPage JSON-LD). Generated by
  `scripts/build-service-pages.mjs` from the homepage data — re-run it
  (`npm run build:pages`) after any change to services in `index.html`.
- `api/` — Vercel serverless functions (Node):
  - `GET /api/availability` — open slots for a day (regular hours + Private
    Hours: early 7–9am, after 7pm, Sundays; +$15/service).
  - `POST /api/book` — booking + Stripe Checkout session; full payment at
    booking; optional gift code (balance applied, remainder stays on the
    code); $10 first-visit offer. Custom consultations and fully
    gift-covered bookings confirm with no payment.
  - `POST /api/gift-buy` — Stripe Checkout for any-amount gift certificate
    ($10 minimum custom); the receipt IS the certificate. Gift codes
    NEVER expire.
  - `GET /api/gift-balance?code=` — remaining balance.
  - `GET /api/gift-status?session_id=` / `GET /api/booking-status?session_id=`
    — confirmation pages after Stripe checkout.
  - `POST /api/pay-spot` — studio enters the amount owed (+ optional gift
    code); returns a Stripe payment link as `https://boltonfacials.com/pay?id=…`.
    The client pays on THEIR OWN phone (text / email / QR code). Email
    sending via Resend when the contact is an email. Automatic texting is
    NOT set up (Resend is email-only) — for text, the studio texts the link
    from their own phone.
  - `GET /api/pay-link?id=` — what `/pay.html` uses to open Stripe checkout.
  - `POST /api/stripe-webhook` — verifies the Stripe signature; marks
    bookings paid, issues gift codes, records payments.
  - `api/admin/*` — magic-link + password sign-in, session, bookings
    calendar, today's payments.
- `lib/` — shared server code: `kv.js` (Vercel KV / Upstash REST),
  `schedule.js` (catalog + weekly schedule + prices),
  `stripe.js`, `email.js` (Resend), `bookings.js` (storage + emails),
  `auth.js` (admin sessions).
- `pay.html`, `booked.html`, `gift-sent.html` — the client-facing flow pages
  (served at `/pay`, `/booked`, `/gift-sent` via `vercel.json` rewrites).
- `admin/` — private studio pages (NOT linked from the public site):
  `index.html` (magic-link / password sign-in), `dashboard.html` (today's
  payments, calendar, pay flow).
- `llms.txt`, `robots.txt`, `sitemap.xml`, `vercel.json`.

## Local development

```sh
npm install
npx vercel dev        # serves the site + api/ locally (needs `vercel` CLI login)
# or, static preview only (no api/):
python3 -m http.server 8000
```

Copy `.env.example` to `.env` for local values. Never commit `.env`.

## Regenerating service pages

```sh
npm run build:pages
```
